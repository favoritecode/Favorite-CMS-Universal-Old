========================================================================
Favorite CMS Universal - Version 1.0.14
"One CMS. Any Website."
========================================================================

Thank you for choosing Favorite CMS Universal, a lightweight, modular,
standalone PHP Content Management System engineered for standard shared
hosting and local development environments.

QUICK INSTALLATION (2 MINUTES):
------------------------------------------------------------------------
1. Extract the contents of this archive into your web hosting document root
   (e.g., public_html/ or htdocs/) or any subdirectory (e.g., public_html/blog/).

2. Open your website in any web browser:
   http://your-domain.com/
   (or http://localhost/your-folder/)

3. Follow the friendly 2-minute setup wizard:
   - System environment compatibility check
   - MySQL database connection setup
   - Site title and administrator account creation

4. Click "Install Favorite CMS".
   Your site is now ready to use!

SYSTEM REQUIREMENTS:
------------------------------------------------------------------------
- PHP 8.1.0 or newer
- Required PHP Extensions: pdo, pdo_mysql, mbstring, json, session, fileinfo, gd
- MySQL 5.7+ or MariaDB 10.3+ (InnoDB support)
- Apache 2.4+ (with mod_rewrite enabled) or LiteSpeed
- Zero Node.js, Python, Composer, or Git required on production hosting

ADMINISTRATION:
------------------------------------------------------------------------
Access your administration dashboard at:
http://your-domain.com/admin
